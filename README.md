# Toonel
A black and white comic-style website displaying articles and artwork. It features a clean layout with a grid design for easy navigation.

## Key Features

- **Grid Layout**: Organized articles displayed in a responsive grid format for easy viewing on all devices.
- **Black and White Aesthetic**: A minimalist design that emphasizes content with a striking black and white contrast.
- **Interactive Elements**: Hover effects that enhance user engagement and provide visual feedback.
- **Clean Typography**: Readable fonts that complement the comic style, ensuring a comfortable reading experience.
- **Article Links**: Direct links to articles for seamless navigation to more in-depth content.

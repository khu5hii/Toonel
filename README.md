# Toonel

**Toonel** is a black-and-white, comic-style web magazine that showcases articles and artwork through a clean, modern grid-based layout. Designed with simplicity and readability in mind, Toonel focuses on content-first presentation while adding subtle interactivity to enhance user engagement.

## ✨ Features

### 🧩 Grid-Based Layout
- Articles displayed in a responsive grid format  
- Optimized for desktop, tablet, and mobile devices  

### ⚫⚪ Black & White Aesthetic
- Minimalist comic-inspired design  
- Strong contrast to keep the focus on content  

### 🖱️ Interactive UI
- Hover effects on article cards and links  
- Smooth visual feedback for better engagement  

### ✍️ Clean Typography
- Readable fonts designed for long-form reading  
- Typography complements the comic-style theme  

### 🔗 Article Navigation
- Direct links to full articles  
- Seamless browsing experience  

### 🔄 Auto-Fetched Articles
- Articles dynamically loaded using JavaScript  
- Data fetched from a backend API  
- No manual HTML updates required when adding new articles  

### 📱 Responsive Scroll Animations
- Smooth scroll-based animations  
- Optimized for both mobile and desktop screens  

### 🖥️ Node.js Backend
- Built with **Express.js**  
- Serves article data via REST API  
- CORS enabled for frontend-backend communication  

---

### Backend
- Node.js

---

## ⚙️ How It Works

- The frontend fetches article data from the Express.js backend using JavaScript  
- The backend exposes API endpoints that return article content in JSON format  
- New articles can be added by updating the backend data source without modifying frontend code
